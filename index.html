How your secret is stored

  1. Encrypted in your browser. A text, or a file of up to 128 KB, is locked with a new random key (AES-256-GCM) before anything is sent. You can add a passphrase as a second lock.
  2. The key stays in the link. It sits after the #, a part browsers never send, so the server cannot read the secret.
  3. Works once. Pressing “Reveal” hands over the encrypted data and deletes it in the same step.
  4. No accounts, no cookies. Unopened links expire after 1 hour, 1 day or 7 days; files last 1 hour or 1 day. The site’s code stores no accounts, cookies or IP addresses. This page loads nothing from other sites and has no analytics. Cloudflare, which hosts it, handles connections as any host does. Your theme choice is kept in your browser.
